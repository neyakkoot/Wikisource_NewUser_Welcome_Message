# Wikisource New User Welcome Message

## தமிழ் விக்கிமூலம் – புதிய பயனர் வரவேற்பு

**Wikisource New User Welcome Message** என்பது தமிழ் விக்கிமூலத்தில் புதிதாகப் பங்களிக்கத் தொடங்கும் பயனர்களை வரவேற்று, அவர்களுக்கு வழிகாட்டும் நோக்கத்துடன் உருவாக்கப்படும் ஒரு JavaScript கருவியாகும்.

இந்தக் கருவியின் மூலம் புதிய பயனர்களுக்கு தனிப்பயனாக்கப்பட்ட வரவேற்புச் செய்திகளை வழங்கி, தமிழ் விக்கிமூலத்தில் அவர்களின் முதல் பங்களிப்பை எளிதாக்க முடியும்.

## 🎯 நோக்கம்

- புதிய விக்கிமூலம் பயனர்களை வரவேற்றல்
- புதிய பயனர்களுக்கு ஆரம்பநிலை வழிகாட்டுதலை வழங்குதல்
- விக்கிமூலம் பங்களிப்புகளை அறிமுகப்படுத்துதல்
- பயனர் தொடர்பை மேம்படுத்துதல்
- தமிழ் விக்கிமூல சமூகத்தில் புதிய பங்களிப்பாளர்களை ஊக்குவித்தல்

## 🛠️ பயன்பாடு

இந்தக் கருவி, கீழ்க்கண்ட JavaScript நிரலை இறக்குமதி செய்து பயன்படுத்துகிறது:

```javascript
// தமிழ் விக்கிமூலம் - புதிய பயனர் வரவேற்பு

importScript('பயனர்:Neyakkoo/NewUserbutton.js');
```

`NewUserbutton.js` நிரல் தமிழ் விக்கிமூலத்தில் புதிய பயனர்களை வரவேற்கும் பொத்தான் மற்றும் அதனுடன் தொடர்புடைய செயல்பாடுகளை வழங்குகிறது.
